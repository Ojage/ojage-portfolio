# Case Study Images

Drop cover images for the home page case studies here. Naming maps to the
`id` of each project in `src/data/homeData.ts`:

| File | Project id |
| --- | --- |
| `nnact-pro.png` | `nnact-pro` |
| `ai-cultural-app.png` | `ai-cultural-app` |
| `cm-sentinel.png` | `cm-sentinel` |
| `auto-publishing-pipeline.png` | `auto-publishing-pipeline` |

jpg/webp also works. Suggested: 16:9, under ~300 KB.

Once files exist in this folder, I wire them into
`src/data/homeData.ts` (`imageUrl` field) replacing the placeholder name.
